# CueLab

Learn to DJ on your **Pioneer DJ DDJ-FLX4** — a Windows app with step-by-step lessons, a live on-screen controller, a practice studio, free practice music and a study mode.

## Download

Go to **Releases** (right side of this page) and download `CueLab-Setup-x.y.z.exe`. Run it — it installs like any Windows app. New versions install over the old one; your progress is kept.

`CueLab-Portable-x.y.z.exe` runs without installing.

> First run: Windows may say "Windows protected your PC" because the app isn't code-signed yet. Click **More info → Run anyway**.

## What's inside

- **38 lessons** in 4 levels (Basic → Intermediate → Advanced → Pro). Each lesson: **Watch** (the app does it on your decks), **Learn why**, **Do it** (step by step on your FLX4) and a scored **Test**.
- **Live DDJ-FLX4 panel** that mirrors your controller: the control to touch glows pink with an arrow, numbers show the order, buttons with lights flash on the real controller.
- **Help when you go wrong**: names the wrong control and shows how to put it back, warns when you turn the wrong way or miss the timing, shows a close-up after 12 s, and offers Slow mode / Show me / Skip after 3 tries.
- **Practice Studio**: two decks, waveforms, phrase coach, mix health, record your mix.
- **Free music library**: the CueLab Practice Pack is generated by the app and free to use (CC0) — 15 tracks in house, deep house, tech house, hip-hop, drum & bass, lo-fi and a scratch tool. Add your own music (BPM is detected automatically). Export practice tracks as WAV for rekordbox/Serato.
- **Study mode**: Pomodoro timer with lo-fi tracks auto-mixed on your decks.
- Fits any screen: one 1920×1080 layout scaled to the window, no scrolling.

## Controller

The DDJ-FLX4 is USB MIDI class-compliant — no driver needed. In **DDJ-FLX4** in the app:
1. Choose the FLX4 as the audio output (speakers on outputs 1–2, headphone cue on 3–4).
2. Run the **Control test**. If a control isn't recognised, moving it during the test teaches it to the app.

No controller? Click buttons, drag knobs and faders, and drag the jog wheels on screen.

## Build it yourself

```
npm install
npm start        # run
npm run dist     # build the Windows installer into dist/
```

Every push to `main` builds the installer with GitHub Actions and publishes it as a release.
